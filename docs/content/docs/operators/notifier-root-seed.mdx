# Remove validator root seeds from notifiers

The dedicated `ika-notifier` process does not use validator root-seed
material. After upgrading to a release containing this change, remove
`root-seed-key-pair` from the notifier configuration and remove the
`root-seed.key` file or secret mount from the notifier workload.

Legacy notifier configurations that still contain `root-seed-key-pair`
continue to parse, but `ika-notifier` ignores the field without opening the
referenced file. Validator configurations are unchanged: `ika-validator`
still requires `root-seed-key-pair` for MPC operations.
